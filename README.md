# Keyboard Activity Analyzer

## Internship Project
This project is developed as part of the CODTECH Cybersecurity & Ethical Hacking Internship.

## Project Description
A Python-based keyboard activity analyzer that examines user-entered text and generates typing statistics.

## Features
- Character count
- Word count
- Letter frequency analysis
- Security research demonstration
